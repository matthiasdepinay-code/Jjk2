# Guide de conversation

*Phrases prêtes à l'emploi, par situation. Registre haut sauf mention ; au registre bas, abrégez toutes les longues sauf la première de chaque mot (`outils/ghazrun.py bas "..."`). Pour comprendre une forme : `outils/ghazrun.py analyse <forme>`. La grammaire de la conversation est dans `README.md`, § 9.*

---

## 1. Saluer, se présenter

| Ghâzrûn | Français | Note |
|---|---|---|
| **Vorz thatar.** | Salut. (Du feu vers toi.) | la salutation ordinaire |
| **Vorz thartar.** | Salut à vous. | |
| **Vorz tâzzhâ.** | Bienvenue. (Le feu est ici.) | |
| **Ûkh thôk kâ ?** | Comment t'appelles-tu ? | ton nom, quoi ? |
| **Ûkh ghôk Nôkhzhâl.** | Je m'appelle Nôkhzhâl. | pas de copule |
| **Kâvôr thôrnath ?** | D'où viens-tu ? | |
| **Mârdrîmvôr thôrnagh.** | Je viens du Mârdrîm. | |
| **Vîthath kâghan ?** | Comment vas-tu ? (tu vis comment ?) | |
| **Vîthagh thâmok. Dha tha ?** | Je vais bien. Et toi ? | |
| **Vîthagh slîm.** | Je vais mal. (je vis faible) | |
| **Tha thûm ghôk.** | Tu es mon ami. | pas de copule au présent ; passé : *Thûm ghôk vânônath.* |
| **Drûth zrâgot.** | Adieu, bonne route. (Que la route te trouve.) | |
| **Nôkh shûlot.** | Bonne nuit. (Que la nuit te garde.) | |
| **Zhûnthôrnûshagh.** | Je reviendrai. | |

## 2. Politesse

| Ghâzrûn | Français |
|---|---|
| **Vorzghâz.** | Merci. |
| **Narzûgûth.** | De rien. (Pas de dette.) |
| **Narkrûshâ.** | Pardon, excuse-moi. |
| **Narkâ.** | Ce n'est rien. |
| **Ô ghûrkâ lûm.** | Apporte de l'eau, s'il te plaît. |
| **Ô dhârâ nîk.** | Attends un peu, je te prie. |
| **Ûn.** / **Nar.** / **Vaikâ.** | Oui. / Non. / Peut-être. |
| **Thîrdhûm.** | Certainement. |
| **Narthûlagh.** | Je ne sais pas. |
| **Narrûnkhôragh.** | Je ne comprends pas. |
| **Ô ghâzâ zhûn, dhârok.** | Répète, lentement, s'il te plaît. |
| **Ghâzath Ghâzrûn kâ ?** | Parles-tu le Ghâzrûn ? |
| **Ghâzagh nîk.** | Je le parle un peu. |
| **Tâz rûnghâz kâ ?** | Qu'est-ce que ça veut dire ? (ceci signifie quoi ?) |

## 3. Demander, répondre

| Ghâzrûn | Français |
|---|---|
| **Kâzhâ khâr ?** | Où est le seigneur ? |
| **Khâr thâlzhâ.** | Le seigneur est dans la tour. |
| **Kâzhâ lûm ?** | Où y a-t-il de l'eau ? |
| **Lûm drîmôk vôrkzhâ.** | L'eau est derrière la maison. |
| **Kânâl thôrnar ?** | Quand arrivent-ils ? |
| **Dâltar, dâlthûzzhâ.** | Demain, à l'aube. |
| **Kâghan grâmaghar ?** | Comment y allons-nous ? |
| **Drâzghan.** | À cheval. (par la monture) |
| **Kâvôr nîlath ?** | Pourquoi pleures-tu ? |
| **Zûm thûm ghôk ghûmôn.** | Parce que mon ami est mort. |
| **Kâ ûrgath ?** | Que veux-tu ? |
| **Ûrgagh mûkhûth dha dhôlûth.** | Je veux à manger et à dormir. |
| **Tha kâ ?** | Qui es-tu ? |
| **Gha varkh, gha nargor.** | Je suis un guerrier, je ne suis personne. |
| **Thûlath ûl… ?** | Sais-tu que… ? |
| **Zhâlônath kâ ?** | As-tu vu quelque chose ? |
| **Zhâlônagh narkâ.** | Je n'ai rien vu. |

## 4. Se déplacer

| Ghâzrûn | Français |
|---|---|
| **Grâmaghar.** | Allons-y. |
| **Thôrnâ.** / **Thôrnâr.** | Viens. / Venez. |
| **Dhârâ tâz.** | Reste ici. |
| **Vôrkgrâmâham.** | Suis-moi. (vôrkgrâm-â-h-am : le *-h-* évite deux voyelles en contact) |
| **Drûth Khâstrûntar kâzhâ ?** | Où est la route vers Khâstrûn ? |
| **Drûthzhâ kâ ?** | Est-ce loin ? |
| **Nar, nîkzhâ. Ghrum nâl.** | Non, c'est près. Trois heures. |
| **Zhorgôk vôrkzhâ.** | Derrière la montagne. |
| **Brâzgrâmaghar lûmdrûth.** | Nous traversons la rivière. |
| **Ûlârgrâmâ !** / **Zhaggrâmâ !** | Monte ! / Descends ! |
| **Zhârgrâmâ.** | Entre. |
| **Vôrgrâmâr !** | Sortez ! |
| **Dhôlaghar nôkhdrîmzhâ.** | Nous dormons dans la grotte. |
| **Drûthgrâmaghar dâlthûzzhâ.** | Nous partons à l'aube. |

## 5. Manger, boire, dormir

| Ghâzrûn | Français |
|---|---|
| **Gûlkok gha.** | J'ai faim. (je suis affamé) |
| **Slûgûrgok gha.** | J'ai soif. |
| **Dhôlûrgok gha.** | Je suis fatigué. |
| **Ghazhâ brûkh dha krîsh.** | J'ai du pain et du sel. |
| **Ô dôrâham ghrôsh.** | Donne-moi de la viande, s'il te plaît. |
| **Mûkhâ.** / **Slûgâ.** | Mange. / Bois. |
| **Thâmok kâ ?** | C'est bon ? |
| **Thâmok bôrg.** / **Zhûrkok. Khrûgok.** | Très bon. / Mauvais. Amer. |
| **Slûgvorz ghazhâ nar.** | Je n'ai pas d'alcool. (phrase sans verbe : *nar* en fin) |
| **Vorzmûkhagh slûm.** | Je cuis du poisson. |
| **Vorzdôrâ.** | Allume le feu. |
| **Narvorzâ.** | Éteins le feu. |
| **Dhôlaghar tâznâl.** | Nous dormons maintenant. |
| **Nardhôlâ ! Dâl !** | Réveille-toi ! Il fait jour ! |

## 6. Au marché

| Ghâzrûn | Français |
|---|---|
| **Nâkhdôr tâzôk kâ ?** | Quel est le prix de ceci ? |
| **Khâl zôrnîk.** | Cinq pièces. |
| **Zôrbôrg bôrg !** | Beaucoup trop cher ! |
| **Ghrum, dha tâkdôraghar.** | Trois, et nous faisons affaire. |
| **Zôrdôragh tâz.** | J'achète ceci. |
| **Narzôrnâkhagh drâkh ghôk.** | Je ne vends pas mon épée. |
| **Thazhâ zôrnîk kâ ?** | As-tu de l'argent ? |
| **Zûgûth thôk nâk zôrnîk.** | Tu me dois quatre pièces. (ta dette : quatre pièces) |
| **Nâkhdôrônagh.** | J'ai payé. |
| **Bûlûn tâzok, nâkhdôr dûzok.** | Même chose, autre prix. |

## 7. Danger, guerre

| Ghâzrûn | Français |
|---|---|
| **Zhândôrâ !** | À l'aide ! (donne la main !) |
| **Ghîlzhambar thôrnar !** | Les hommes arrivent ! (registre bas, insulte) |
| **Nârkh zhorgzhâ.** | L'ennemi est dans la montagne. |
| **Nâk zûl varkh.** | Quarante guerriers. |
| **Ûzgâr ! Thûrz dha drâkh !** | Debout ! Armure et épée ! |
| **Shûlâ zhâr.** | Garde la porte. |
| **Narrûmâ.** | N'aie pas peur. |
| **Rûmagh narkâ.** | Je ne crains rien. |
| **Mûrkâhuz.** / **Mûrkâruzardhûm.** | Tue-le. / Tuez-les tous. |
| **Nîrgûn gha. Nârg bôrg.** | Je suis blessé. Beaucoup de sang. |
| **Vîthgor kâzhâ ?** | Où est un guérisseur ? |
| **Ghûmôn.** | Il est mort. |
| **Thrôkh gharôk !** | La victoire est à nous ! |
| **Dhârûth tâznâl.** | La paix, maintenant. |
| **Hûshâr. Khôrâr.** | Taisez-vous. Écoutez. |

## 9. Temps qu'il fait, temps qui passe

| Ghâzrûn | Français |
|---|---|
| **Thângûth kâ tâzdâl ?** | Quel temps fait-il aujourd'hui ? |
| **Krîl, dha lûmglûm.** | Il fait froid, et il pleut. |
| **Kôr lîkhok. Vorzân.** | Le soleil brille. Il fait chaud. |
| **Vâshdhûm thôrn.** | Une tempête arrive. |
| **Shîl zhorgzhâ nâlvôr.** | Il y a déjà de la neige sur la montagne. |
| **Krîlnâl drûthok.** | L'hiver est long. |
| **Kânâl ? Nôkhrûn.** | Quelle heure ? Minuit. |
| **Dâlghûmzhâ.** | Au crépuscule. |
| **Kôrnâlar ghôk zhîk.** | J'ai neuf ans. (mes années : neuf) |
| **Nâl grâm thrâmok.** | Le temps passe vite. |
